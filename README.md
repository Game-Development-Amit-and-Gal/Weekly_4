# 🌌 Space Landing


---

## 🎮 איך משחקים?

* הזז את החללית עם מקשי החיצים.
* השתמש בדחיפה עדינה כדי לשלוט במהירות הירידה.
* התחמק ממכשולים שמופיעים אקראית.
* נסה לנחות על כוכב הלכת בלי להתרסק.

---

## 🪐 מטרת המשחק

לשרוד את מסלול הירידה, להתחמק ממכשולים, ולהנחית את הספינה על כוכב לכת מסתובב.

---

## 💥 מכשולים

* מופיעים באופן אקראי במרחב.
* פגיעה בהם גורמת לסיום המשחק.

---

## 🌍 כוכב הלכת

* מושך את החללית באמצעות כוח כבידה מותאם אישית.
* אם עוברים את הכוכב ולא נוחתים עליו → מעבר למסך Game Over.

---

## 🔄 מסך Game Over

במקרה של התרסקות או פספוס כוכב הלכת:

* מוצגת כותרת **Game Over**.
* מופיע כפתור Restart לחזרה לסצנה הראשית.

---

## 🛠️ טכנולוגיות בשימוש

* Unity 6
* Rigidbody + כוח כבידה מותאם
* UI Canvas (טקסט + כפתור)
* מעבר בין סצנות באמצעות SceneManager
* Skybox מותאם לחלל

---

## 🎯 מטרת התרגיל

המשחק נבנה לצורך תרגול ויישום:

* פיזיקה בסיסית
* שליטה וחוויית שחקן
* UI וניווט בין סצנות
* יצירת עולם חלל ו־Skybox
* ניהול מכשולים ודיטקטציה של התנגשויות
